📦 Schritt 1: GitHub Upload

Neues Repository auf GitHub erstellen

Gehe zu github.com/new

  • Repository Name: ganglefinanzierung
  • Beschreibung: "Finanzierungsvisualisierung für 3-Parteien Stockwerkeigentum"
  • Public oder Private (nach Wunsch)
  • Klicke "Create repository"
Remote hinzufügen und Code hochladen

Öffne PowerShell und führe folgende Befehle aus:

cd "c:\Users\tinur\OneDrive\Hausbauen\Stockwerkeigentum_Finanzierung\ganglefinanzierung" # Remote hinzufügen (ersetze YOUR_USERNAME durch deinen GitHub Username) git remote add origin https://github.com/YOUR_USERNAME/ganglefinanzierung.git # Branch umbenennen falls nötig git branch -M main # Code hochladen git push -u origin main
ℹ️ Info: Du wirst aufgefordert dich einzuloggen oder einen Personal Access Token zu verwenden.
✓ Erfolg! Der Code ist jetzt auf GitHub verfügbar unter: https://github.com/YOUR_USERNAME/ganglefinanzierung

🚀 Schritt 2: Vercel Deployment

Vercel Projekt erstellen
  1. Gehe zu vercel.com
  2. Melde dich an oder registriere dich
  3. Klicke "New Project"
GitHub Repository verbinden
  1. Wähle "Import Git Repository"
  2. Verbinde dein GitHub-Konto wenn nötig
  3. Suche nach "ganglefinanzierung" und wähle es
Build-Einstellungen überprüfen

Vercel erkennt Next.js automatisch. Die Einstellungen sollten so aussehen:

Feld Wert
Framework Preset Next.js
Build Command npm run build
Output Directory .next
Deployment starten

Klicke "Deploy" und warte auf die Fertigstellung (etwa 2-3 Minuten)

✓ Live! Deine Website ist nun verfügbar unter: https://ganglefinanzierung.vercel.app

🔧 Troubleshooting

⚠️ Git Push funktioniert nicht?

Überprüfe, dass du entweder dein GitHub-Passwort eingegeben hast oder einen Personal Access Token verwendest. Normale Passwörter funktionieren nicht mehr.

⚠️ Vercel Build-Fehler?

Überprüfe die Logs im Vercel Dashboard unter "Deployments". Häufig liegt es an fehlenden Dependencies.

ℹ️ Port 3000 schon in Nutzung? npm run dev -- -p 3001
